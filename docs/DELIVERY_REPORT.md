## ۸. نمونه تشخیص خطا و بازخورد آموزشی

- گزینه «۳/۷» برای ۲/۳+۱/۴ ← تشخیص کتاب: «جمع صورت‌ها و مخرج‌ها جداگانه» ← مقوله مفهومی ← بازخورد سه‌بخشی (چرا غلط / راه اصلاح / تمرین مجدد) + در تمرین خطایابی مرحله F دانش‌آموز باید خطای علی را خودش پیدا کند.
- الگوی تکرار: دو خطای مفهومی پیاپی ← تصمیم موتور `alternative-representation` (REPEATED_MISCONCEPTION) به‌جای تمرین تکراری.
- راهنمای کامل در سه تلاش ← مقوله «پاسخ حدسی» (بدون برچسب منفی) با یادآوری آرام.
- دستیار: «در کارنامه تو مقوله … پرتکرار است… این یک فرضیه است، نه قطعیت» — و در نبود شواهد: «شواهد کافی ندارم».
