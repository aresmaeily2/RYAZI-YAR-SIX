# راهنمای تست (TESTING)

ابزار: **Vitest 2** با محیط jsdom و Testing Library.

## اجرا

```bash
npm test           # اجرای یک‌باره همه تست‌ها
npm run test:watch # حالت مشاهده برای توسعه
```

## لایه‌های تست

| فایل | پوشش |
|---|---|
| `tests/mathEngine.test.ts` | ارقام فارسی/عربی، ب.م.م، چهار عمل کسری، کسر وسط، XP، تسلط وزنی، درس‌های تکمیل‌شده، زنجیره روزانه، گرد/قطع، دایره/استوانه/درصد |
| `tests/answerChecking.test.ts` | تصحیح MCQ، نرمال‌سازی ورودی عددی (فارسی/عربی، ممیز با نقطه/٫ و /، جداکننده هزارگان)، کسر معادل و عدد مخلوط، مخرج صفر، خطای مجاز، نمونه‌برداری از پاسخ‌های واقعی کتاب |
| `tests/examEngine.test.ts` | ساخت آزمون جامع/موضوعی، نمره‌دهی ترکیبی (درست/غلط/بی‌پاسخ)، سقف و کف درصد، برچسب نتیجه، استخراج غلط‌ها و بی‌پاسخ‌ها |
| `tests/curriculumData.test.ts` | یکپارچگی ساختار: ۷ فصل، یکتایی شناسه‌ها، سازگاری شناسه پرسش با والد، گزینه درست یگانه، ۳ راهنمایی، ارجاع صحیح تشخیص اشتباه، پوشش سطوح دشواری، تطابق عناوین فصل‌ها با سرفصل رسمی کتاب، ≥۸۰ پرسش |
| `tests/app.test.tsx` | UI: رندر اولیه، RTL، ناوبری ۴ تب، انتخاب فصل/درس، پاسخ درست و غلط با بازخورد، اعتبارسنجی ورودی خالی، راهنمایی ۳مرحله‌ای، جریان کامل آزمون (نمره ۱۰۰٪ و ۰٪ + تمرین مجدد غلط‌ها)، حالت خالی گزارش، بازیابی وضعیت پس از رفرش |

## اصول

- تست‌های UI تعامل واقعی کاربر را شبیه‌سازی می‌کنند (`userEvent`) نه فراخوانی مستقیم تابع داخلی.
- وضعیت `localStorage` بین تست‌ها پاک می‌شود (`tests/setup.ts`) تا تست‌ها مستقل بمانند.
- هیچ تستی حذف یا `skip` نمی‌شود؛ اگر تستی قرمز شد علت واقعی آن رفع می‌شود.
