# Design System ریاضی‌یار ششم — «تخته‌سنگ ریاضی» (Math Slate)

نسخهٔ ۱.۰ | مالک محصول: ریاضی‌یار | اعمال‌شده از SHA نسخهٔ ارتقای بصری به بعد

---

## ۱. فلسفه و اصول

استعارهٔ مرکزی: **دفتر ریاضی دانش‌آموز زیر نور صبحگاهی** — کاغذ شطرنجی روشن، جوهر بنفش-نیلی، هیجان کهربایی، خطای مهربان. اصول پنج‌گانه:

1. **فهم مقدم بر تزئین** — هر حرکت/رنگ یا به درک مفهوم کمک می‌کند یا به هویت؛ در غیر این صورت حذف است.
2. **یک زبان، چهار صحنه** — پس‌زمینهٔ هر تاب متفاوت است اما از همان گرید کاغذی، همان نور و همان خانوادهٔ رنگ ساخته شده.
3. **حرکت یعنی معنا** — حرکت فقط برای بازخورد، گذار وضعیت و هدایت توجه؛ هرگز نمایشی/تکراری.
4. **فارسی در مرکز** — RTL بومی، اعداد با isolate، هیچ شکست خط یا هم‌پوشانی در ترکیب فارسی/لاتین.
5. **دسترس‌پذیری غیرقابل مذاکره** — کنتراست AA، فوکوس مرئی، Reduced Motion کامل، اهداف لمسی ≥۴۴px.

## ۲. رنگ (Color Tokens)

| توکن | مقدار | کاربرد |
|---|---|---|
| `brand.50…900` | خانوادهٔ نیلی-بنفش (#EEF2FF … #312E81) | هویت اصلی: هدر، CTA، فعال، فوکوس |
| `brand-gradient` | `#4F46E5 → #7C3AED` (۱۳۵deg) | Hero، دکمهٔ اصلی، نشان فعال |
| `sun.400/500/600` | کهربایی گرم (#FBBF24/#F59E0B/#D97706) | انگیزه: امتیاز، راهنما، زنجیره |
| `success` | Emerald 50/200/600/800 | پاسخ درست، تسلط |
| `danger` | Rose 50/200/600/800 | پاسخ نادرست، خطا |
| `info` | Sky 50/200/600 | اطلاع‌رسانی خنثی |
| `paper` | `#F7F9FF` | پس‌زمینهٔ پایه (کاغذ) |
| `ink.900…400` | Slate 900…400 | متن: عنوان 900، بدنه 700، فرعی 500، راهنما 400 |

قواعد: رنگ معنایی هرگز برای تزئین؛ رنگ فصل‌ها فقط روی نوار/نشان همان فصل؛ متن سفید فقط روی brand.600+ یا گرادیان.

## ۳. تایپوگرافی

- خانواده: **Vazirmatn** (میزبانی محلی، ۶ وزن 400/500/600/700/800/900، `font-display: swap`).
- مقیاس: `text-xs 12 | sm 14 | base 16 | lg 18 | xl 20 | 2xl 24 | 3xl 30`؛ ارتفاع خط متن آموزشی `leading-relaxed`.
- نقش‌ها: عنوان صفحه `2xl Black(900)`؛ عنوان بخش `lg SemiBold(600)`؛ بدنه `sm/base Medium(500)`؛ برچسب و راهنما `xs Medium`؛ عبارت ریاضی `base Bold` با `tabular-nums`.
- ریاضی: `.ltr-nums` (isolate) برای هر عدد/عبارت لاتین؛ `.math-expr` = اندازهٔ بزرگ‌تر + فاصلهٔ حروف + اعداد tabular برای خوانایی کامل عبارات ترکیبی.
- bidi: فارسی RTL بومی؛ فرمول/ورودی عددی همیشه `dir="ltr"` داخل isolate.

## ۴. فاصله، شعاع، سایه، سطح

- فاصله: پایهٔ ۴px؛ ساختار صفحات `space-y-6`، درون کارت `space-y-4`، grid `gap-4/6`.
- شعاع: اجزای تعاملی `xl(12px)`؛ کارت `2xl(16px)`؛ نشان و pill `full`؛ ورودی `xl`.
- سایه: `soft` (سطح آرام: 0 1px 2px + 0 4px 16px −4px با جوهر نیلی ۶–۸٪) | `lift` (hover: لایهٔ دوم عمیق‌تر) | `glow` (هالهٔ برند برای CTA و فوکوس) — همیشه جوهر نیلی، هرگز خاکستری خالص.
- سطح (Elevation): کاغذ (grid) < کارت (soft) < کارت شناور/modal (lift) < اعلان‌ها (glow).

## ۵. پس‌زمینه‌ها (چهار صحنه، یک زبان)

- **پایهٔ مشترک**: `paper` + گرید ۲۸px با جوهر نیلی ۴.۵٪ + هالهٔ نورانی ملایم در گوشهٔ بالا (radial، برند ۵٪).
- **داشبورد**: هالهٔ خورشیدی اضافی سمت چپ‌پایین (کهربایی ۴٪) — گرمای شروع.
- **درس‌نامه/تمرین**: خنثی‌تر؛ تمرکز روی کارت محتوا.
- **آزمون**: هالهٔ آسمانی ملایم — جدیت سنجش.
- **گزارش**: دو هالهٔ برند/خورشیدی متقارن — روایت دستاورد.
- اشکال شناور اختصاصی (aria-hidden): علامت‌های ÷ × ＋ = و π ٪ با opacity ≤۰٫۱۲ فقط در Hero و نتیجهٔ آزمون.

## ۶. اجزا (Components)

- **دکمهٔ برند** `.btn-brand`: گرادیان برند، سایهٔ glow، hover: ارتفاع +۲px و عمق بیشتر، active: فشرده‌شدن ۹۷٪.
- **دکمهٔ نرم** `.btn-soft`: سطح brand.50، متن brand.700، hover سطح برند۱۰۰.
- **کارت** `.card`: سفید، شعاع ۲xl، سایهٔ soft، حاشیهٔ slate-100؛ hover قابل‌کلیک: lift + بلندشدن ۲px.
- **nav اصلی**: کپسول سطح slate-100/70 با نشانگر فعال گرادیان + خط زیرین متحرک؛ هدف لمسی py-2.5.
- **گزینهٔ پاسخ**: کارت کوچک با نشان گزینهٔ گرد؛ انتخاب: ring برند ۲px + scale ۱٫۰۲ + پرشدن برند؛ صحیح: حاشیه/پس‌زمینهٔ success + تیک pop؛ نادرست انتخابی: danger + shake ملایم.
- **بازخورد**: نوار رنگی کناری ۴px + آیکون متحرک + پس‌زمینهٔ معنایی ۵۰ + ورود `pop`؛ تشخیص سوءبرداشت با برچسب «پزشک خطا».
- **پیشرفت**: نوار با فیل گرادیان متحرک (۷۰۰ms) و حباب درصد؛ حلقهٔ تسلط در کارت فصل.
- **حالت‌ها**: Loading = اسکلتون شیمر با همان شعاع کارت‌ها؛ Empty = تصویرسازی خطی + پیام مهربان + CTA؛ Error = نگهبان ErrorBoundary با CTA بازگشت؛ Disabled = opacity ۵۰ + cursor ممنوع + بدون سایه؛ Focus = حلقهٔ ۳px برند با offset ۲px (همه‌جا یکسان).

## ۷. سیستم حرکت (Motion)

توکن‌ها: `--motion-fast:150ms | base:250ms | slow:400ms`؛ easing فنری استاندارد `cubic-bezier(.34,1.56,.64,1)` برای pop و `cubic-bezier(.22,1,.36,1)` برای گذار.

| انیمیشن | keyframe | کاربرد | مدت |
|---|---|---|---|
| `pop` | scale .92→1 + fade | بازخورد، کارت جدید، نشان | 250ms |
| `rise` | translateY 12px + fade | ورود بخش‌ها و گذار مراحل | 400ms |
| `shake` | translateX ±4px ×۳ | پاسخ نادرست | 400ms |
| `tick` | scale 0→1.2→1 | آیکون موفقیت | 400ms |
| `float` | translateY ±8px alternate ∞ | اشکال شناور تزئینی | 7s |
| `fill` | width transition | نوار پیشرفت | 700ms |
| `pulse-soft` | scale 1→1.04 ∞×۳ | زنجیره/دعوت به اقدام | 2s |

قاعدهٔ Reduced Motion: همهٔ انیمیشن‌ها و float/pulse در `prefers-reduced-motion: reduce` غیرفعال؛ فقط گذار opacity ساده باقی می‌ماند (الگوی موجود `.solver-pop` به کل سیستم تعمیم یافت).

## ۸. تصویرسازی و آیکون

- آیکون: lucide-react — قلم واحد stroke 2، اندازه‌های 14/16/20/24، همیشه `aria-hidden` و داخل حباب رنگی نرم برای نقش‌های معنایی.
- تصویرسازی: اشکال هندسی SVG خطی با قلم برند (دایره، مثلث، خط‌کش، پرگار) + علامت‌های ریاضی شناور؛ سبک خطی یکدست، بدون استوک؛ فقط در Hero، Empty و پایان مسیر.
- نمودارها: میله/حلقه با رنگ برند و برچسب فارسی؛ هیچ نموداری بدون aria-label نیست.

## ۹. قواعد توسعه (Guardrails)

1. هیچ هاردکد رنگ جدید در مؤلفه‌ها؛ فقط توکن‌های این سند (Tailwind theme) + رنگ‌های معنایی.
2. هر انیمیشن جدید باید در جدول §۷ ثبت و زیر Reduced Motion بیاید.
3. `data-testid` و props و منطق مؤلفه‌ها هرگز با تغییر ظاهری عوض نمی‌شوند.
4. هر مؤلفهٔ مشترک جدید باید در همین سند مستند شود.
