# مدل داده (DATA MODEL)

## انواع اصلی (`src/types/curriculum.ts`)

| نوع | توضیح | فیلدهای کلیدی |
|---|---|---|
| `Chapter` | فصل کتاب | `id` (ch1…ch7)، `number`، `title`، `subtitle`، `color`، `lessons` |
| `Lesson` | درس | `id` (chXlY)، `conceptSteps`، `formulaBox`، `workedExamples`، `interactiveLab`، `questions` |
| `WorkedExample` | مثال حل‌شده | `steps[]` (گام‌به‌گام)، `finalAnswer`، `conceptualTip` |
| `Question` | پرسش | دو واریانت با discriminator `type` |
| `McqQuestion` | چهارگزینه‌ای | `options[]`، `correctAnswer`، `misconceptions[]` |
| `NumericQuestion` | ورودی عددی | `answerKind` (integer/decimal/fraction)، `acceptedAnswers[]`، `toleratedError?` |
| `AttemptRecord` | یک تلاش ثبت‌شده | `isCorrect`، `hintsUsed`، `source` (practice/exam)، `diagnosedMisconception?` |
| `LearnerState` | وضعیت یادگیرنده | `xp`، `streakDays`، `lastVisited*`، `completedLessonIds`، `attempts[]`، `reviewPlan?`، `flowProgress?` (موقعیت ازسرگیری جریان‌های آموزشی — حفظ مرحله پس از خروج/ورود مجدد) |
| `ChapterMastery` | تسلط فصل | `masteryPercent`، `status`، `weakLessonIds` |

## قاعده نام‌گذاری شناسه‌ها

- فصل: `ch<شماره>` → ch1 … ch7
- درس: `ch<شماره فصل>l<شماره درس>` → ch1l3
- پرسش: `q<شماره فصل><شماره درس><شماره پرسش>` → q134 یعنی فصل ۱، درس ۳، پرسش ۴
- مثال: `ex<فصل><درس><شماره>` → ex52

تست `tests/curriculumData.test.ts` این قاعده را به‌صورت خودکار اعتبارسنجی می‌کند.

## قواعد محتوایی تضمین‌شده با تست

1. هر پرسش دقیقاً ۳ راهنمایی پله‌ای دارد.
2. گزینه درست MCQ دقیقاً یک‌بار میان گزینه‌ها آمده و تشخیص‌های اشتباه به گزینه‌های موجود (و نابرابر با پاسخ درست) ارجاع می‌دهند.
3. هر درس حداقل یک مثال حل‌شده با ≥۲ گام و نکته آموزشی دارد.
4. در هر فصل حداقل یک پرسش «دشوار» و در کل کتاب هر سه سطح دشواری حاضرند.
5. پاسخ‌های عددی همیشه با موتور تصحیح (`isNumericAnswerCorrect`) قابل پذیرش‌اند — این ویژگی با تست نمونه‌برداری از همه پرسش‌های عددی کنترل می‌شود.

## قالب پشتیبان JSON

`LearnerState` عیناً به JSON تبدیل و از فایل بازیابی می‌شود. تابع `importStateJson` ساختار را کامل اعتبارسنجی می‌کند (نوع فیلدها، عدم منفی بودن XP، معتبر بودن تلاش‌ها) و داده خراب را رد می‌کند؛ بنابراین فایل پشتیبان دستکاری‌شده نمی‌تواند اپ را بشکند.

## مدل امتیازدهی

- **XP**: درست بدون راهنمایی و تلاش اول = `وزن دشواری × ۱۵` (آسان ۱۵، متوسط ۳۰، دشوار ۴۵)؛ هر راهنمایی ۳ واحد جریمه؛ حداقل ۵؛ تلاش مجدد درست ۴۰٪؛ پاسخ نادرست ۲ امتیاز تلاش آموزشی.
- **تسلط وزنی فصل**: درستِ تازه/بدون راهنمایی = وزن کامل؛ درست با راهنمایی = ۰٫۸۵؛ درست بعد از اشتباه = ۰٫۶ (و ثبت درس ضعیف)؛ بدون درست = ۰. آستانه‌ها: ≥۸۰٪ «تسلط کامل»، ≥۵۵٪ «خوب».
- **زنجیره روزانه**: فعالیت در روز بعد از آخرین فعالیت → +۱؛ وقفه → بازنشانی به ۱؛ محاسبه بر پایه تاریخ UTC.
